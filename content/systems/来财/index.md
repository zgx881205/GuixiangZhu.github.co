### 项目简介
 <div class="project-justify">
   
“来财商城”智能客服系统是面向全品类电商消费者的全天候导购与售后问答平台，针对商品参数、成衣尺码选购、售后配送政策、场景搭配推荐等高频电商咨询场景，整合商品规格说明与平台运营规则，基于检索增强生成（RAG）技术与双路混合检索构建商城专属知识库，将回答严格限定在权威资料与实时业务数据范围内，有效破解通用大模型在电商领域的“价格过时”与“知识幻觉”难题。
 
 </div>

#### 功能特性

- **智能问答核心**：以自然语言多轮问答为核心，支持上下文感知的会话理解、逐字流式交互与文档依据溯源引用
- **电商专属能力**：内置成衣智能尺码匹配、动态场景搭配推荐、以及与商城核心系统联动的实时价格与库存核验
- **敏捷知识管理**：支持 Markdown 结构化商品切片管理，具备商品上下架与规格变更自动增量同步更新机制

#### 技术架构

- **基础平台**：基于电商 RAG 混合检索架构（语义向量 + 关键词全文检索 + Rerank 候选精排）
- **分层架构**：采用 Next.js (App Router) 前端交互商城与 Medusa 2.x (TypeScript) 现代化电商引擎的分层架构
- **数据底座**：基于 PostgreSQL 16 统一承载电商业务交易数据与专属向量知识库（laicai_knowledge）
- **实时交互**：经 Server-Sent Events (SSE) 流式传输协议实现打字机式低延迟实时交互
- **模型接入**：基于 OpenAI 标准协议，无缝接入 DeepSeek、Qwen（通义千问）、Kimi、GPT 等主流商用及开源大模型
- **协同调度**：在智能回复中集成商品卡片上下文渲染与可下单状态二次校验
- **权限与风控**：支持基于 Medusa Publishable API Key 的多区域多渠道安全鉴权机制
